# FinAllyAI - Your Financial Copilot 🤖💰

FinAllyAI is an AI-powered financial assistant designed for young people in Africa. It helps users manage their budget, track goals, and understand financial markets through a conversational interface.

## 🚀 Live Demo
**Try it now:** [https://finally-ai.netlify.app](https://finally-ai.netlify.app)

## ✨ Features
- **AI Chat:** Ask any financial question and get instant answers.
- **Budget Tracker:** Manage your monthly income and expenses.
- **Goal Setting:** Create and track your savings goals.
- **Market Data:** Real-time crypto prices and exchange rates.
- **Google Auth:** Secure login with Firebase.
- **PWA:** Install it on your phone like a native app.

## 🛠️ Tech Stack
- Frontend: HTML, CSS, Vanilla JS (PWA)
- Backend: Cloudflare Workers (Relay)
- AI: Google Gemini
- Auth & Hosting: Firebase, Netlify
